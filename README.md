About
This repository contains the website for YoungMinds.app, an innovation and entrepreneurship learning platform for school students. YoungMinds creates hands-on experiences where students explore problems, build prototypes, and develop their own ideas.
What we offer
Programme / Initiative	What it is
Innovation School	Guided tinkering, design thinking, and prototype-building experiences for school students.
YoungPreneur.ai	A 100-day entrepreneurship journey for teenagers to develop and test a startup idea.
₹99 Startup Idea Session	A 60-minute, 1:1 online mentor session for ages 13–18 to explore a startup idea.
TinkerGram Community	A community for student-led and mentor-led tinkering and innovation activities.
Mandan Universe	Hands-on innovation workshops and idea challenges.

Analytics and privacy
The Startup Idea Session landing page uses Google Analytics 4 (GA4) through Google Tag Manager (GTM), subject to the site's cookie-consent controls.

The analytics implementation measures interactions such as:
- Landing-page views and section visibility
- Scroll depth
- Testimonial video engagement
- FAQ and review interactions
- Booking-button and contact-link clicks
Analytics is not enabled before a visitor accepts analytics cookies. Visitors can decline or withdraw their choice using Cookie settings. Meta Pixel tags remain paused.

GA4 booking-button clicks indicate interest in booking, not completed Wise.live bookings or confirmed payments.
Privacy review: The applicability of India's Digital Personal Data Protection framework to analytics involving visitors under 18 remains an open review item. The current implementation should not be described as legally compliant solely because cookie consent is present.

See the Privacy Policy for the website's published privacy information.
Development and deployment
The production website is served at www.youngminds.app. Changes to the production branch should be reviewed and tested before deployment.

For local setup, refer to the repository's current project configuration and scripts. This README deliberately does not prescribe installation commands because the build tooling and scripts have not been independently verified.

Before deploying website changes, check:
1. Desktop and mobile layout, navigation, and booking links.
2. Consent behaviour for Accept, Decline, and withdrawal.
3. GA4 event delivery and duplicate-event prevention.
4. Meta Pixel remains disabled unless separately approved.
5. Performance and accessibility using Lighthouse or PageSpeed Insights.
